## 🧠 Mental Framework

我的思考与行动准则，源于对技术与人性的双重审视。

🌊 **活如鱼龙，静如山水**
这是我对自己的期许。在需要行动时如鱼龙般灵活敏捷，在需要沉淀时如山水般宁静深远。动静之间，寻找平衡。

🌲 **深度优先 (Depth-First)**
面对知识的海洋，我选择深度优先而非广度优先。在一个领域扎根，直到触及本质，然后再向外延伸。真正的理解来自于深入，而非表面的浮光掠影。

❤️ **技术服务于人 (Tech for Humans)**
技术的终极目标不是技术本身。AI不应是冰冷的替代者，而应是人类能力的延伸。最好的产品，是在细节中体现用心，在体验中传递温度。
