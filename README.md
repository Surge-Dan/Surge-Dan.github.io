## 🌟 Highlights of This Site

这个个人主页是我对 **"无框架主义"** 的一次尝试。为了追求极致的加载速度和完全的掌控力，我放弃了 React/Vue 等重型框架，回归 **原生开发**。

* **⚡ Zero Build Step**: 纯原生 HTML/CSS/JS，没有 Webpack，没有 npm install，所见即所得。
* **🎨 Tailwind Art**: 使用 Tailwind CSS (CDN) 构建了一套 `Warm Beige` (暖米色) + `Deep Earth` (深褐) 的高级配色系统。
* **✨ Smooth Interactions**:
    * **Hero Section**: 静态文字与动态画框分离，彻底消除闪烁。
    * **Hover Effects**: 实现了类似 iOS 的阻尼感悬停、卡片上浮、多层弥散阴影。
    * **Dynamic Charts**: 纯 CSS/JS 手绘的动态增长条形图与环形图。
* **📱 Fully Responsive**: 完美的移动端适配与磨砂玻璃导航栏。

## 🛠️ Tech Stack

* **Core**: Semantic HTML5
